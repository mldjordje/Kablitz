# Production launch checklist

Status initially OPEN. An unchecked item is not evidence of compliance. Record date, reviewer, environment, configuration/commit and test evidence for each item. Mark N/A only with an approved explanation.

- [ ] Kablitz legal identity and contact verified; Impressum/privacy accessible on all devices.
- [ ] Approved privacy texts reflect actual production services and all user-facing language versions.
- [ ] Processing inventory, purposes/bases, retention and data-rights contact approved.
- [ ] Processor contracts, regions/subprocessors and international access reviewed, including ADSPIRE/Serbia.
- [ ] Browser network/storage checked before choice, after reject, accept and withdrawal; optional services behave correctly.
- [ ] Map/video embeds, fonts and analytics reviewed; no unexpected third-party requests.
- [ ] Project/service submissions are validated server-side, stored privately and delivered correctly; anti-abuse checked.
- [ ] Upload restrictions and private downloads checked, including another user's access and expired links.
- [ ] Google allowlist, verified identity, role matrix and account/session revocation tested at server endpoints.
- [ ] Unauthorized users cannot read admin, inquiry, media or analytics data; unpublished projects remain private.
- [ ] Secret handling, sanitization, dependency status and secure session/header configuration checked.
- [ ] Logging/error monitoring redaction and retention verified with synthetic data.
- [ ] Data access/export/correction/deletion workflow and retention jobs verified; backup restore tested.
- [ ] Keyboard/mobile/reduced-motion/globe-list alternatives checked; BFSG applicability documented.
- [ ] Media licenses, customer/employee releases and technical/marketing claims approved.
- [ ] Incident contacts, immediate alerts, daily review, transfer safeguards and notification decision owner documented.
- [ ] Source snapshots refreshed/reviewed; failed downloads investigated; relevant legislative changes checked.
- [ ] Kablitz responsible person/legal adviser has approved legal texts and open applicability decisions.
